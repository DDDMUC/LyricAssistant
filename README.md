# 词格（cige-grid）

按词格逐字填中文歌词的桌面工具：把作曲给的词格（如 `4/4`、`2/2/3`）摆成田字格，
对着格子填词，不用自己数字数，也不会超格或漏格。

## 功能

- **钉子格**：打字覆盖当前格，后面的字不会被顶走；删字原地留空，先写好的句尾始终待在自己的格子里
- 句内分组（如 `2/2/3`），`+` / `−` 只作用于光标所在的分句
- `Alt + ←/→` 整句挪动一格，会把字挤出词格时自动拦截
- 每句可存多个备选写法，随时切换对比；备注不占格子
- 段落管理：新增、删除、上移、下移
- 撤销 / 重做，自动保存，未保存标记
- 导入：粘贴、读剪贴板、`.txt` / `.lrc` / `.md` 文件，空行自动分段，可合并到现有歌词
- 导出：工程 `.json`、歌词 `.txt`，一键复制歌词到剪贴板
- 复制 / 粘贴句
- 浅色 / 深色 / 跟随系统主题

## 使用

### 开发环境

需要 Node.js 与 Rust（[Tauri 前置条件](https://tauri.app/start/prerequisites/)）。

    npm install
    npm run tauri dev

### 测试与构建

    npm test
    npm run tauri build

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Cmd/Ctrl + S` | 保存 |
| `Shift + Cmd/Ctrl + S` | 另存为 |
| `Cmd/Ctrl + Z` | 撤销 |
| `Shift + Cmd/Ctrl + Z` / `Ctrl + Y` | 重做 |
| `Alt + ←/→` | 整句左 / 右挪一格 |
| `← / → / ↑ / ↓` | 在格子 / 句子间移动光标 |
| `Enter` | 移到下一句 |
| `Backspace / Delete` | 原地删字 |

## 技术栈

Tauri 2 + TypeScript + Vite + Vitest。
