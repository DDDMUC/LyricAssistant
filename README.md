# 词格（cige-grid）

按词格逐字填中文歌词的桌面工具：把作曲给的词格（如 `4/4`、`2/2/3`）摆成田字格，
对着格子填词，不用自己数字数，也不会超格或漏格。

## 功能

- **钉子格**：打字覆盖当前格，后面的字不会被顶走；删字原地留空，先写好的句尾始终待在自己的格子里
- 句内分组（如 `2/2/3`），`+` / `−` 只作用于光标所在的分句；`／` 在光标处断句或与上一分句合并
- `Alt + ←/→` 整句挪动一格，会把字挤出词格时自动拦截
- 每句可存多个备选写法（可重命名），随时切换对比；备注不占格子
- 段落管理：新增、删除、上移、下移
- 左侧「歌词文件」边栏：新建 / 切换 / 删除多个歌词文件，自动保存到本地、重启还原
- 撤销 / 重做，自动保存，未保存标记
- 导入：粘贴、读剪贴板、`.txt` / `.lrc` / `.md` 文件；可选**仅词格**或**同时导入歌词**（自动填字）；支持《标题》、段落关键词（Verse/Chorus/主歌/副歌…，可带数字、括号、冒号）、`[段落名]`、行尾（备注）、`|` 或 `※` 备选、纯数字词格行、`XXXX` 占位行、空行分段（无分段标记时每 4 句自动分段）、合并导入
- 导出：主按钮「导出歌词」直接写 `.txt`，可选带上全部备选（`※` 分隔）与备注——导出的 TXT 可原样再导入；「保存工程」写 `.json`（含备选、备注，可再次打开）；一键复制歌词到剪贴板
- 复制 / 粘贴 / 清空句；`⧉` 一键复制本句词格插入新句
- 溢出处理：写到末格后多出的字不丢，暂存为该句溢出（标红「＋…」并计数）；「整理溢出」一键顺移到下一句，末句溢出自动新建一句
- 创作信息：导入时自动提取「作词：… / 作曲：… / 编曲：… / 二胡：…」等 credit 行（含一行多条、英文标签），不生成词格；credit 块中夹着的短裸行会识别为歌名；顶栏「创作信息」可查看编辑，导出可选写在歌词上方并可回读
- 韵脚提示：自动识别每句句尾的十三辙韵部，同韵同色，状态栏汇总；句尾未填时灰显、不计入统计
- 浅色 / 深色 / 跟随系统主题

## 使用

### 开发环境

需要 Node.js 与 Rust（[Tauri 前置条件](https://tauri.app/start/prerequisites/)）。

    npm install
    npm run tauri dev

### 测试与构建

    npm test
    npm run tauri build

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Cmd/Ctrl + S` | 保存 |
| `Shift + Cmd/Ctrl + S` | 另存为 |
| `Cmd/Ctrl + Z` | 撤销 |
| `Shift + Cmd/Ctrl + Z` / `Ctrl + Y` | 重做 |
| `Cmd/Ctrl + [` / `Cmd/Ctrl + ]` | 光标所在分句减 / 加一格 |
| `Cmd/Ctrl + \` | 光标处断句 / 与上一分句合并 |
| `Alt + ←/→` | 整句左 / 右挪一格 |
| `← / → / ↑ / ↓` | 在格子 / 句子间移动光标 |
| `Enter` | 移到下一句 |
| `Backspace / Delete` | 原地删字 |

## 技术栈

Tauri 2 + TypeScript + Vite + Vitest。
